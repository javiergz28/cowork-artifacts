Todo lo que medimos,
ciclo a ciclo.

Cada dos o tres días se procesa un lote de reportes de Mercado Libre y se publica un panel con el estado del negocio a esa fecha. Los ciclos de un mismo mes se van acumulando hasta el cierre mensual. Acá queda guardado todo el histórico: podés abrir el panel de cualquier fecha tal como se publicó ese día.

Reportes mensuales

Fuente: reportes exportados de Mercado Libre UY, cruzados con el maestro STOCK_MT_FINAL.

Los paneles se generan con el ciclo /multitrend-ciclo y se publican en GitHub Pages. Las cifras son las que informa Mercado Libre en cada corte; cuando algo es inferencia o hipótesis, el panel lo dice.
